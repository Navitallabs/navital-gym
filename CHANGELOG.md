# Changelog

## Unreleased (pre-launch) -> v1.0.0
- **GST prompts now name the answer fields (27 Oct 2026).** The standard GST questions did not say which fields the grader scores (`tax_type`, `required`, `eligible_invoices` ...), so a correct answer under another key failed (an earlier Sonnet GST run scored 30% on the standard split because of this). Each standard GST prompt now ends with the answer fields of its question type (`navital_gym/envs/gst/__init__.py`); the easy prompts are unchanged. The grader, worlds and tasks did not change. The earlier GST standard rows are excluded and not published; GST standard rows are being re-run on the new prompts and appear once complete. Every other row was re-graded by replay at the new grader id. `scripts/verify_submission.py` now checks the transcript against the prompt the agent is shown today, so runs made with the old GST prompts are rejected.
- **Stale env-README text removed (27 Oct 2026).** The GST, UPI and form_multidoc env READMEs still said no model had been run, that the env was a draft or pre-release, or carried internal planning notes (licence "to be confirmed", team-internal paths); they now point to the leaderboard and `docs/RESULTS.md` and give the licence plainly (Apache-2.0 code, CC BY 4.0 data). Documentation only inside `navital_gym/`: no grading code changed, but the tree id changed, so every run was re-graded by replay at the new id. `docs/RESULTS.md` also now explains that est. USD 0.00 on Sarvam rows means not estimated (Sarvam is not in our price table), not free.
- **Internal status text and names removed from the public data and comments (27-28 Oct 2026).** The 50 core support tasks no longer carry a `meta.review_status` field (it held an internal draft note; no review status is claimed; the experimental and easy support tasks keep their honest "machine-assisted / AI-drafted, not native-reviewed" label). Teammate names and internal paths were removed from comments, docstrings and harness cases, `trip/tasks_growth.jsonl` was renamed `tasks_source.jsonl` (same rows, same task ids), and `docs/HINDI-CHECK.md` states the disclosure neutrally. Tree id changed, so every run was re-graded by replay: no score changed.
- **Sonnet price lookup (27 Oct 2026).** `make_agent` now prices Claude Sonnet models at 5/25 USD per million tokens (input/output) instead of the provider default of 2/10, which is the Haiku-level rate; an explicit `--price-in/--price-out` still wins. The Claude Sonnet 5.5 form and GST full runs had been priced at 2/10, so their est. USD (0.48 and 0.61) was low by exactly 2.5x and is now 1.19 and 1.53. This changes cost estimates only, not any score. The form_multidoc README sentence comparing it with Form Desk now states the measured numbers.
- **Held-out task generator moved out of the public tree (27 Oct 2026).** No grading code changed; the private evaluation sets cannot be reproduced from the repository. This is a new tree id and every run was re-graded by replay at it. The public task sets are unchanged.
- **Grader freeze (26-27 Oct 2026).** `navital_gym/` is frozen for the soft launch (tag `v1.0.0-rc2` = the GST answer-field change above; rc1 had tree id 7d0a72acd069, and an interim id bedd312626b7 only removed internal paths from the task-source build scripts: `build_tasks.py` now take a path or an environment variable). No scoring rule changed. Any later grader change is a new tree id, a re-grade of the saved runs by replay, and an entry here.
- **Versions.** Package and task set are 1.0.0 ("Navital Gym v1.0"). The benchmark tasks are v1.0; the core Python API stays at `API_VERSION = "0.1"` and may still change.
- **`graded_with`** is now the git tree id of `navital_gym/` (same in any repo holding the same code, unchanged by docs-only commits). Verify with `git rev-parse v1.0.0:navital_gym`. The leaderboard and results no longer list run commits (they pointed at private history).
- **Trip package data** ships only `tasks.jsonl` and `tasks_easy.jsonl`; leaderboard export includes easy runs; `regrade.py` skips non-run files.
- **Baselines.** First sampled baselines on all five envs. Small and mid-size models (claude-haiku-4-5, gpt-4o-mini, free-tier models where the quota allowed) on 15-task stratified samples, k=1; Claude Sonnet 5.5 as a larger-model reference on smaller samples. See `docs/RESULTS.md`.
- **Trip grader fix.** An empty stay object (`{}` or `{"hotel_id": null, "rooms": []}`) now means "no hotel this night", like omitting `stay`. It had been rejected as a format error. All rows in `docs/RESULTS.md` were re-graded with the fixed grader (`scripts/regrade.py`, no model calls); the fix changed the format-failure rate of 4 gpt-4o-mini trip answers (27% to 0%) and no pass@1.
- **Trip format errors** name the offending field (for example `days[3].stay.hotel_id must be a string ...`), and the one format-repair retry now covers format-gate failures as well as unparseable replies.
- **Spend limits.** The public runner has no hard-coded spend cap: you pay your own provider and can set `--spend-cap-usd` / `--token-cap` yourself. The project's own caps live in a local file outside the repo (`~/.navital-gym/caps.json`); our run scripts set `NAVITAL_REQUIRE_CAPS=1`, so a paid provider refuses to run in them without a configured cap.
- **Runner:** one format-repair retry with JSON mode on the final answer, a forced final answer when the turn limit is hit, retry with backoff on 429 / 5xx, provider errors reported separately from wrong answers, strict (no-repair) and format-failure columns, token and dollar caps with a file-locked spend ledger, credential redaction in saved files, providers: Ollama, OpenAI, Groq, Gemini, OpenRouter, Anthropic.
- **Fairness tooling:** `scripts/regrade.py` re-grades saved runs from their transcripts (tool calls replayed on a fresh world, so state-graded envs reproduce exactly); `scripts/merge_runs.py` merges two parts of the same sample; `scripts/make_results.py` builds `docs/RESULTS.md` only from saved run files.
- **Core:** `summarize()` reports `by_split` and `by_kind`; a well-formed empty answer earns no partial credit (the format gate is not scored); arriving in the city where a trip ends counts as visiting it.
