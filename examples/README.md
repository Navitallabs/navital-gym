# Examples
`quickstart.ipynb`: install, list the envs, see what an agent sees, run the reference solver on 3 tasks, plug in any OpenAI-compatible model (key from an environment variable; the cell skips itself without one), read the results per split, regrade a saved run. Runs top to bottom with no API key and nothing but the standard library (about 2 minutes).

Run it: open it in Jupyter or Colab. Outside Colab, from this folder `pip install -e ..` first or just run the first cell (it installs from the checkout).
