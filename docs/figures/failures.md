**Model's final answer (trimmed):** ````json {   "status": "plan",   "answer": {     "action": "dispute_raised",     "reason": "failed_txn_debited",     "failed-but-debited money": {       "type": "p2m",       "tat_date": "2026-11-20",       "days_late": 0,       "compensation_rs": 0,       "compensation_automatic": true     }   } } ````
